Execution Procedure

Quick 3-step setup to launch the StockPulse client on any standard Windows 64-bit workstation.

STEP 01

Extract Archive

Unpack the downloaded zip archive to a local folder of your choice.

Expand-Archive StockPulse-Windows.zip -Dest .\StockPulse
STEP 02

Verify Runtime

Ensure the standard .NET 8 Desktop Runtime (x64) is present on your system.

dotnet --list-runtimes
STEP 03

Launch Application

Run the binary. The client connects securely to the Railway backend cluster.

.\WarehouseInventory.exe

Architectural Specifications

Strict compliance with the DCIT 318 Product Requirements Document.

Layer 1 • Presentation

WPF & MVVM Pattern

  • Strict View-ViewModel decoupling via CommunityToolkit.Mvvm
  • Zero business logic and zero networking code inside XAML code-behind
  • Virtualized DataGrid with 300ms debounced search & pagination
  • Safe window lifecycle management with explicit OnMainWindowClose
Layer 2 • Business Logic

Validation & Domain Rules

  • Client-side input pre-validation rejecting non-integer and $\le 0$ quantities
  • Stock-out quantity limits validated against on-hand inventory
  • Dynamic low-stock threshold detection (Quantity $\le$ ReorderLevel)
  • Role-based command authorization matching user security context
Layer 3 • Data & Networking

Stateless HTTPS Integration

  • Direct HTTPS over TLS 1.3 to Railway Cloud backend
  • Strongly-typed DTOs with System.Text.Json deserialization
  • In-memory token storage (passwords and tokens never written to disk)
  • Forced cache-control bypass (no-cache, no-store)
Quality • Test Coverage

Automated Verification

  • 38 automated xUnit test cases covering all layers
  • API client mock testing (200 OK, 400 validation, 401, 403, network drop)
  • Zero-warning compilation policy enforced (TreatWarningsAsErrors)
  • Published as an optimized win-x64 single-file executable
